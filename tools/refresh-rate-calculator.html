Refresh rate calculator.

See how long one refresh or rendered frame takes.

RATE INPUT NC / 03

Enter a rate.

Rate type

FRAME DURATION LIVE

Time per frame.

1,000 ms ÷ 144 Hz

6.944 ms

At 144 Hz, one display refresh takes about 6.944 milliseconds.

THE CALCULATION

There are 1,000 milliseconds in one second. Divide 1,000 by the number of refreshes or frames per second to find the time for one.

Frame duration (ms) = 1,000 ÷ rate per second

This is a nominal frame duration, not a measurement of frame-time variation.
