BITS ARE NOT BYTES

Mbps means megabits per second. MB/s means megabytes per second. One byte contains 8 bits, so 100 Mbps transfers at up to 12.5 MB/s.

Time = file size in bytes ÷ speed in bytes per second

Calculations happen in your browser. No data is sent anywhere.
