ABOUT HASHING

Cryptographic hashing converts input data into a fixed-length hexadecimal string. The same input always produces the same hash, but changing even one character produces a completely different hash. Hashing is not encryption—a hash cannot be reversed to recover the original data.

Verifying a file's hash against a publisher's official checksum helps detect corruption or tampering, but does not independently establish that a file is safe or authentic.

All hashing is performed locally in your browser. Your data is never uploaded or stored.
