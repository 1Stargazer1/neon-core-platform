Calculation mode

eDPI is useful for comparing settings within the same game. Different games use different sensitivity scales.

CS2 uses the documented Source-family default yaw (0.022); Overwatch uses a published yaw value (0.0066). Updates or custom configs may differ.

eDPI = mouse DPI × in-game sensitivity. Compare eDPI within the same game's scale only.

HOW TO USE IT

Use eDPI to compare settings in the same game. Use the converter only with listed yaw presets or a verified custom yaw. cm/360 estimates how far the mouse moves for one full turn.

Example: 800 DPI × 1 sensitivity = 800 eDPI

Yaw reference: KovaaK's Sensitivity Matcher theory documents the Source-family default (0.022) and Overwatch (0.0066). Presets are baselines, not guarantees for modified configs or every game version.

Cross-game results are only as reliable as each game's verified yaw and settings.
