WHAT A CHECKSUM TELLS YOU SHA-256 / SHA-512

Compare file contents.

A cryptographic checksum is a digest of a file's binary contents. Matching an expected digest indicates the checked bytes match that reference; it does not prove that the file is safe or malware-free.

Files are processed in this browser only. Nothing is uploaded or saved. The 100 MiB limit exists because Web Crypto digest is not streaming and may require the complete file in memory.
