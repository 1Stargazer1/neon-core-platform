BITS / BYTES / UNITS

Speed units ending in b/s are bits per second; units ending in B/s are bytes per second. Eight bits equal one byte. K/M/G/T units use powers of 1,000; Ki/Mi/Gi/Ti units use powers of 1,024.

Data = speed in bytes/second × duration in seconds

This is an ideal estimate; protocol overhead and speed variation are not included.
